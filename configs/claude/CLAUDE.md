# Claude Global Preferences

## Permissions
- Run commands, edit files, and make changes freely within the current project directory without asking for permission each time.
- Do not pause to confirm routine operations (installs, file edits, running tests, git operations within the project).
- Ask only for actions that are destructive beyond the project (e.g. system-wide changes, pushing to remote, opening PRs).

## Commits
- Do not add `Co-Authored-By` lines to commit messages.
- Do not add any Claude/AI attribution to commits.

## Style
- Keep responses concise. No padding, no summaries restating what was just done.
- No emojis unless asked.
- Do not overuse em dashes (—). Use them sparingly; prefer plain sentence structure.
